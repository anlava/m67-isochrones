## 1. Цель

Выделить кандидатов в субгиганты в рассеянном скоплении M67 (NGC 2682)  
по фотометрии Gaia DR3 в области поворота главной последовательности  
и зафиксировать правило, метрику и условия остановки  
**до** наложения какой-либо модели изохроны (Cavallo 2024, Bossini 2019).

## 4. Правило отбора кандидатов в субгиганты

### 4.1. Определение

Субгигант (subgiant) — звезда, покинувшая главную последовательность,  
но ещё не вышедшая на ветвь красных гигантов. На CMD субгиганты  
расположены между главной последовательностью (MS) и красными гигантами,  
т.е. **краснее** MS при той же видимой звёздной величине G.

### 4.2. Явное правило (эмпирическое, по наблюдаемым данным)

**Правило S1** (Subgiant Selection Rule 1):

> Кандидат в субгиганты — звезда с 11.5 ≤ G < 13.5, для которой  
> **BP − RP > med(BP−RP | G)** + 0.10 mag,  
> где `med(BP−RP | G)` — скользящая медиана цвета по всем звёздам,  
> попавшим в окно [G − 0.25, G + 0.25) mag по G. Окно строится  
> для каждой звезды индивидуально; медиана вычисляется по  
> одномерному массиву цветов соседей, без интерполяции.

Порог **0.10 mag** — эмпирический, выбран вручную после  
визуального осмотра CMD (рис. `turnoff_cmd_gaia_only.png`).  
При меньших значениях (0.05, 0.07 mag) в выборку попадают  
звёзды на красном краю главной последовательности.  
При большем значении (0.15 mag) теряются субгиганты,  
образующие «ручку» области поворота.

**Альтернатива (явное сечение):**  
> **BP − RP > 1.00 mag** для G < 12.5,  
> **BP − RP > 0.90 mag** для 12.5 ≤ G < 13.5.  

Это сечение выбрано визуально по CMD. В протоколе фиксируются  
оба правила; **основным** считается **S1** (скользящая медиана + порог).  
S2 — резервное, для проверки устойчивости.

### 4.3. Выходной файл

`experiment/turnoff/subgiant_candidates_ids.csv` — CSV с колонками:

- `GaiaDR3` — идентификатор (строка)  
- `Gmag` — видимая величина  
- `BP_RP` — цвет  
- `rule` — каким правилом отобран (`S1` или `S2`)  

Файл содержит **только** звёзды, удовлетворяющие правилу S1.  
Правило S2 используется для сравнения в диаграмме.

## 5. Метрика

Для количественного сравнения с моделями (после наложения изохрон)  
предлагается метрика:

**Остаток цвета при фиксированном G (colour residual at fixed G):**  
> **r_∥ = C_obs − C_model(G)** [mag],

где C = BP − RP. Остаток измеряется **по горизонтали** на CMD  
(G фиксирована, сравниваются цвета). Положительный r_∥ означает,  
что звезда краснее модели при данной G; отрицательный — синее.

**Агрегация по кандидатам:**
- медиана r_∥ по кандидатам в субгиганты  
- медиана |r_∥|  
- сравнение D = med|r_∥(Cavallo)| − med|r_∥(Bossini)|

## 6. Условия остановки

Количественное сравнение (расчёт остатков, бутстрэп,  
вывод D) **останавливается безрезультатно** при любом из:

| № | Условие | Действие |
|---|---|---|
| 1 | Файл `subgiant_candidates_ids.csv` не совпадает с набором, полученным независимым воспроизведением из `data/raw/m67_members_hr2023.tsv` | Запись в журнал: «Ошибка воспроизведения набора ID» |
| 2 | Синтетическая проверка «знак + величина» не проходит (см. §7.2) | Запись: «Синтетический тест не пройден: остаток r ≠ заданному s с точностью 1e-8» |
| 3 | Число кандидатов < 10 | Запись: «Недостаточно кандидатов для сравнения» |
| 4 | Нарушено однозначное покрытие модельной кривой (как в METHOD.md, §2) | Запись: «Модельная кривая: неоднозначность или разрыв» |
| 5 | Изохроны Cavallo/Bossini не содержат ни одной точки label=1 в диапазоне 11.5–13.5 G_app | Запись: «Модель не покрывает область поворота» |

## 7. Две независимые проверки

### 7.1. Проверка 1: восстановление набора ID из исходного TSV

**Файл:** `experiment/turnoff/check_recover_ids.py`

**Команда:**  
```sh
python experiment/turnoff/check_recover_ids.py
```

**Суть:** скрипт читает `data/raw/m67_members_hr2023.tsv` независимо  
от основного пайплайна (собственный парсер), применяет те же фильтры  
(Name == NGC_2682, конечные G/BP/RP, 11.5 ≤ G < 13.5) и то же  
правило S1, затем сравнивает полученный набор GaiaDR3-идентификаторов  
с `experiment/turnoff/subgiant_candidates_ids.csv`.

**Критерий:** оба набора содержат одни и те же GaiaDR3 (сравнение  
множеств). Допускается совпадение по строкам без учёта пробелов.

**Ожидание:** скрипт завершается с кодом 0 и сообщением  
«PASS: набор ID полностью восстановлен».

### 7.2. Проверка 2: знак и величина вертикального остатка  
на синтетической ветви с известным сдвигом

**Файл:** `experiment/turnoff/check_synthetic_residual.py`

**Команда:**  
```sh
python experiment/turnoff/check_synthetic_residual.py
```

**Суть:**  
1. Определяется синтетическая линия цвета:  
   **C_ref(G) = 0.70 + 0.20 × (G − 11.5)** для 11.5 ≤ G < 13.5.  
2. Генерируются 20 тестовых точек: G внутри интервала,  
   цвет = C_ref(G) + s, где s ∈ {−0.05, 0, +0.05} mag.  
3. Для каждой точки вычисляется остаток: r = C_obs − C_ref(G).  
4. Проверяется, что |r − s| ≤ 1e-8 mag.  

**Критерий:** все точки проходят проверку.  
Дополнительно: если в формуле остатка искусственно поменять  
знак (r → −r), проверка падает.  

**Ожидание:**  
- На корректной реализации: код 0, «PASS: все 20 точек»  
- На «испорченной» (перевёрнутый знак, `--flip-sign`): код 1,  
  «FAIL: 12/20 не совпали» (12 из 20 имеют ненулевой сдвиг;  
  точки с s = 0 проходят независимо от знака формулы)

## 8. Запрет на сравнение моделей

До фиксации данного протокола и успешного прохождения  
обеих независимых проверок расчёт преимущества  
Cavallo (2024) или Bossini (2019) **запрещён**.

Новый эксперимент, использующий этот протокол:  
- Должен начаться с **нового коммита**, фиксирующего `TURNOFF_PROTOCOL.md`  
- Первый прогон — только проверки (§7.1 и §7.2)  
- Второй прогон — CMD + отбор кандидатов  
- После — остановка. Сравнение моделей — отдельный шаг  
  с отдельным протоколом.
