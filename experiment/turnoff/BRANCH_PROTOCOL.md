# Протокол выбора ветви для сравнения изохрон в области поворота M67

**Дата фиксации:** 2026-11-22  
**Основание:** коммит 17be1db (протокол TURNOFF_PROTOCOL.md)

---

## 1. Источник документации по фазам PARSEC

Использованные изохроны: PARSEC 1.2S + COLIBRI,  
сгенерированы через CMD 3.9 ([stev.oapd.inaf.it](https://stev.oapd.inaf.it/cgi-bin/cmd_3.9)).

Значения столбца `label` (10-й столбец, `$10` в обеих `.dat`-таблицах)  
соответствуют стандартным фазам PARSEC:

| label | Фаза | Обозначение |
|---|---|---|
| 0 | Предглавная последовательность | PMS |
| **1** | **Главная последовательность** | **MS** |
| **2** | **Ветвь субгигантов** | **SGB** |
| 3 | Ветвь красных гигантов | RGB |
| 4 | Горение гелия в ядре | core He / RC |
| 5–6 | Асимптотическая ветвь гигантов | AGB / TP-AGB |
| 7 | После AGB | Post-AGB |
| 8 | Белые карлики | WD |
| 9 | Точка завершения | termination |

**Вывод:** субгигантам соответствует **label = 2**.

---

## 2. Правило выбора ветви (P2)

**Правило P2** (Phase Selection Rule for Turnoff Comparison):

> Для каждой модели (Cavallo, Bossini) берутся **все** точки с `label = 2`  
> (субгигантская ветвь), извлекаются их `G_app` и `BP_RP`.  
> Соседние точки в порядке исходной таблицы образуют отрезки.  
> Разрывы между блоками одного label не соединяются.

---

## 3. Критерий однозначного покрытия

Для заданной звёздной величины G (наблюдаемой) требуется:

1. **Покрытие:** существует хотя бы один отрезок label=2,  
   на котором G лежит между `G_app` левой и правой границы отрезка  
   (включая границы).
2. **Единственность:** все отрезки, покрывающие данную G,  
   дают одно и то же значение цвета (с точностью до численного  
   совпадения линейной интерполяции на концах общего отрезка).
3. **Запрет экстраполяции:** точка G строго между узлами отрезка  
   или точно на узле. Выход за крайний узел label=2 не допускается.
4. **Запрет пересечения фаз:** если label=2 отсутствует или  
   не покрывает диапазон 11.5–13.5 G_app, расчёт останавливается.

### Условия остановки (дополнение к §6 TURNOFF_PROTOCOL.md)

| № | Условие | Действие |
|---|---|---|
| 6 | Ни одна точка label=2 не покрывает наблюдаемую G звезды | Пропуск звезды; если все пропущены — остановка |
| 7 | Два разных цвета для одной G (внутри label=2) | Остановка: неоднозначность ветви |
| 8 | label=2 не найден в файле модели | Остановка: нет субгигантской фазы |

---

## 4. Метрика (остаток цвета при фиксированном G)

Из TURNOFF_PROTOCOL.md §5:

> **r_∥ = C_obs − C_model(G)** [mag],  
> где C = BP − RP, а `C_model(G)` — линейная интерполяция  
> по отрезку label=2, содержащему G.

Применяется только к кандидатам S1, для которых label=2  
даёт ровно одно значение цвета при их G.
