# Протокол подбора возраста M67 по области поворота (Turnoff Fitting)

**Дата фиксации:** 2026-11-22  
**Авторы протокола:** AI4Science-агент  
**Статус:** протокол зафиксирован. Подгонка по наблюдениям **не производилась**.

---

## 1. Цель

Получить **отдельную оценку возраста** M67 для каждой из двух параллельных расчётных сеток PARSEC 1.2S.

Внутри каждой сетки меняется только параметр **logAge** (шаг 0.05 dex в диапазоне ~9.30–9.70). Остальные параметры фиксированы на значениях справочных публикаций:
*   **Сетка A (Cavallo 2024):** [Fe/H] = 0.32, Av = 0.18, dMod = 9.64.
*   **Сетка B (Bossini 2019):** [Fe/H] = 0.00, Av = 0.115, dMod = 9.726.

Задача — сравнить полученные оценки возраста и оценить их согласованность с учётом систематических различий между моделями.

---

## 2. Данные и отбор

### 2.1. Наблюдения
*   **Источник:** Hunt & Reffert (2023), VizieR `J/A+A/673/A114/members`.
*   **Область интереса:** Весь диапазон поворота главной последовательности, $11.5 \le G < 13.5$ mag.

### 2.2. Выборка для подгонки
Для подгонки используется **фиксированный набор из 257 звёзд** в указанном диапазоне яркости ($11.5 \le G < 13.5$), включая звёзды у изгиба главной последовательности (Main Sequence turnoff). Этот набор **един для всех возрастов и обеих сеток**. Отбор по правилу S1 (субгиганты) применяется **только для построения диагностического графика**, но не исключает звёзды из расчёта подгонки.

---

## 3. Метрика подгонки (Fit Metric)

Определяем меру близости каждой звезды к модели изохроны в двумерном пространстве CMD ($G$, $BP-RP$).

### 3.1. Расстояние до изохроны
Для каждой наблюдаемой звезды $i$ с координатами $(G_i, C_i)$ и модельной изохроны $\mathcal{I}$ находим точку на изохроне $(G_m, C_m)$, минимизирующую евклидово расстояние в CMD:

$$ D_i = \sqrt{ (G_i - G_m)^2 + (C_i - C_m)^2 } $$

Обе оси измеряются в mag; масштаб фиксирован ($w_G = w_C = 1$, см. §3.2). Фотометрические ошибки Gaia DR3 **не используются** для нормировки осей.

### 3.2. Масштабы осей
Обе оси зафиксированы в физических единицах (mag):
$$ D_i = \sqrt{ (G_i - G_m)^2 + (C_i - C_m)^2 } $$

Веса $w_G = w_C = 1$ — это **фиксированный численный масштаб**, не зависящий от фотометрических ошибок Gaia. Единица расстояния — 1 mag по любой из осей. Масштаб един для всех возрастов и обеих сеток.

### 3.3. Метрика сетки
Для каждого возраста и каждой сетки метрика вычисляется **по одним и тем же 257 звёздам** (см. §2.2). Отсечение по MAD не применяется — все 257 звёзд участвуют в расчёте на равных основаниях.

Итоговая метрика сетки для данного возраста:
$$ M = \text{median}(D_1, D_2, \ldots, D_{257}) $$

Медиана выбрана как робастная статистика, устойчивая к единичным выбросам (возможные неразрешённые двойные или нечлены скопления). Агрегация без отбрасывания точек гарантирует, что метрика сравнивает одно и то же множество звёзд на всех возрастах.

## 4. Синтетический тест (Synthetic Test)

Проверяем способность методики восстанавливать известный возраст при наличии шума и двойных звёзд. Тест **не зависит от наблюдательных данных M67** — синтетические системы генерируются с нуля.

### 4.1. Параметры генерации (фиксированные)

| Параметр | Значение |
|---|---|
| Истинные возраста (два) | 2.5 Грд (logAge = 9.398), 3.6 Грд (logAge = 9.556) |
| Число систем в реализации | **257** (как в реальной выборке, §2.2) |
| Начальная функция масс | Kroupa (2001), двухсегментная: $\xi(m) \propto m^{-1.3}$ для $0.08 \le m < 0.5\,M_\odot$, $\xi(m) \propto m^{-2.3}$ для $0.5 \le m \le 3\,M_\odot$ |
| Доля двойных | **15%** (фиксирована) |
| Распределение $q = M_2/M_1$ | равномерное на $[0.5, 1.0]$ (каждый компонент — из той же модели) |
| Фотометрический шум | Гауссов: $\sigma_G = 0.005$, $\sigma_{BP} = \sigma_{RP} = 0.008$ mag (типичные ошибки Gaia DR3 в диапазоне $G \approx 11.5$–$13.5$) |

### 4.2. Процедура одной реализации

Для каждой реализации (K=100 на пару «сетка × возраст»):

1. Выбрать **257 первичных масс** $M_1$ из Kroupa IMF (rejection sampling, $0.08 \le M_1 \le 3\,M_\odot$).
2. Для каждого $M_1$: если случайное число $U(0,1) < 0.15$ (двойная), выбрать $q \sim U(0.5, 1.0)$, вычислить $M_2 = q \cdot M_1$.
3. Для каждого компонента (одиночного или обоих в двойной) получить модельные $G$, $BP$, $RP$ из изохроны истинного возраста (линейная интерполяция по массе). Для масс вне диапазона изохроны — экстраполяция запрещена; масса отбрасывается и выбирается заново.
4. Для двойных: перевести обе тройки величин в потоки ($F = 10^{-0.4 m}$), сложить потоки, перевести обратно в величины.
5. Добавить Гауссов шум с $\sigma$ из §4.1 ко всем величинам $G$, $BP$, $RP$ независимо.
6. Отфильтровать: оставить только системы, попавшие в $11.5 \le G < 13.5$. Если их больше 257 — отбросить лишние случайно; если меньше — добрать новые массы из IMF до заполнения. **Гарантировать ровно 257 систем в реализации.**
7. Вычислить $BP-RP$ для каждой системы.

Результирующий набор из 257 координат $(G, BP-RP)$ **не привязан** к наблюдаемым звёздам M67 — это независимая синтетическая выборка.

### 4.3. Критерий PASS (на одну пару «сетка × возраст»)

Для каждой из четырёх пар (сетка A: 2.5 Грд, сетка A: 3.6 Грд, сетка B: 2.5 Грд, сетка B: 3.6 Грд):

1. Прогнать K=100 реализаций по §4.2.
2. Для каждой реализации $r$: вычислить метрику $M$ (медиану расстояний, §3.3) для **всех возрастов** данной сетки (logAge 9.30–9.70, шаг 0.05 dex). Оценённый возраст $\hat{\tau}_r$ — logAge, минимизирующий $M$.
3. **Пара проходит** (PASS), если минимум **90 из 100** оценок удовлетворяют:
   $$ |\hat{\tau}_r - \tau_{true}| \le 0.05 \text{ dex} $$

**Итоговый вердикт синтетического теста:**
*   **PASS** — все четыре пары прошли критерий.
*   **FAIL** — хотя бы одна пара не прошла.

Порог 0.05 dex равен шагу сетки по logAge. Изменение порога или доли успешных реализаций (90%) допускается только через новую фиксацию протокола.

Расчёт итоговых оценок возраста по реальным данным **запрещён** до выполнения следующих шагов:

2.  **Прохождение синтетического теста:** Все четыре пары прошли критерий PASS (§4.3: ≥90/100 оценок в пределах 0.05 dex от истинного возраста).
3.  **Верификация кода:** Запуск проверок `check_recover_ids.py` и `check_synthetic_residual.py` из каталога `experiment/turnoff/`.
